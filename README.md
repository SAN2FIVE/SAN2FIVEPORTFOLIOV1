# Santosh Bhikale – Portfolio

Personal portfolio of Santosh Bhikale, a software developer working with C#, ASP.NET Core, Angular and SQL Server.

Single static page (HTML, CSS and vanilla JavaScript). No build step and no dependencies apart from the Poppins font from Google Fonts.
